N1MM Logger+

Digital function key files

Function key (.mc) files for digital/RTTY contests in N1MM+. These files pre-configure your F-key messages for each contest. To use, copy the .mc file into your N1MM+ macros folder and load it in the contest setup. Originally sourced from n1mmwp.hamdocs.com.

To install: copy the .mc file to your N1MM+ macros directory (typically C:\Users\[you]\Documents\N1MM Logger+\MacroFiles\), then load it in N1MM+ under Config → Function Keys → Digital.
