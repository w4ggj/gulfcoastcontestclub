Station Setup

Add one row per operating position. The Station Name must match the NetBios/PC name configured in N1MM (shown in packets as StationName). This maps the PC name to a human-readable position label and records the rig/antenna setup.

Remote Operators

Club members operating from their own shacks can feed their QSOs into this dashboard by pointing N1MM's UDP broadcast at the Pi's public IP.

N1MM Broadcast Data Setup

  1. In N1MM go to Config → Configure Ports → Broadcast Data
  2. Check Contacts and Score
  3. Set the IP address to your router's public IP : 12060
  4. On your router, port-forward UDP 12060 → 192.168.4.71
  5. Make sure the contest is set to Live in this admin panel before operators start logging
  6. Each operator's PC NetBIOS name will appear as a separate station on the dashboard — add them in Station Setup above

The Pi's public IP can be found at whatismyip.com from any device on this network.
